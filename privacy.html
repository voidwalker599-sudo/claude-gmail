Privacy policy for Claude Gmail

Last updated: 29 October 2026

What the app is

Claude Gmail is a personal tool that runs on its owner's own Windows PC. It connects the owner's own Gmail accounts to the Claude assistant so that the assistant can help with email when the owner asks. It is used only by its owner.

What data it accesses

With the owner's permission, granted through Google's sign-in screen, the app uses the Gmail API (scope gmail.modify) to search and read messages, send messages, change labels, and move messages to Trash. It cannot permanently delete mail.

Where data goes

  • Sign-in tokens are stored only on the owner's computer. They are never uploaded or shared.
  • Email content is fetched only when the owner asks the Claude assistant to do something with email. It is passed to that assistant for that request.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models by this app.
  • The app has no server and no database of its own.

Google API Services User Data Policy

Claude Gmail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token files on the owner's computer also removes access.
